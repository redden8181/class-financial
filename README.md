# Классная копилка

Простое мобильное PWA-приложение для учёта денежных сборов **одного** школьного класса.

- Список детей (мальчики / девочки), поиск, карточка ребёнка с историей оплат
- Сборы любых категорий: название, сумма с ребёнка, описание, дата
- Дедлайн «Собрать до»: подсчёт оставшихся дней и подсветка просрочки
- Частичные взносы: для долгих сборов деньги можно вносить постепенно
  (100 ₽ сейчас, 200 ₽ позже) — остаток считается автоматически
- Статусы «Сдал / Частично / Не сдал» с датами каждого взноса
- Учёт расходов внутри сбора: на что потратили, сумма, дата, фото чека
- Баланс кассы: собрано − потрачено = остаток
- Статистика по каждому сбору и прогресс-бар
- Экран «Все долги» — кто и сколько должен
- Светлая и тёмная тема
- **Работает полностью офлайн** — все данные хранятся на устройстве (localStorage)
- Обновляется автоматически после обновления репозитория на GitHub

## Запуск локально

```bash
npm install
npm run dev
```

## Публикация на GitHub Pages (один раз)

1. Создайте новый репозиторий на GitHub и загрузите туда все файлы проекта
   (включая папку `.github` и файл `package-lock.json`).
2. Откройте репозиторий → **Settings → Pages → Source** и выберите **GitHub Actions**.
3. Сделайте push в ветку `main` (или запустите workflow вручную во вкладке Actions).
4. Через минуту сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Workflow `.github/workflows/deploy.yml` уже настроен: каждый push в `main`
автоматически собирает проект и публикует новую версию.

## Установка на телефон

### iPhone (Safari)

1. Откройте адрес сайта в **Safari**.
2. Нажмите «Поделиться» → **«На экран "Домой"»**.
3. Иконка появится на рабочем столе — приложение открывается на весь экран
   и работает офлайн после первой загрузки.

### Android (Chrome)

1. Откройте адрес сайта в Chrome.
2. Меню (⋮) → **«Установить приложение»** / «Добавить на главный экран».

## Как работают офлайн и обновления

- При первом открытии приложение целиком кэшируется service worker'ом —
  дальше интернет не нужен.
- При каждом следующем открытии с интернетом приложение проверяет новую
  версию на GitHub Pages. Если вы обновили код в репозитории — телефон
  подхватит обновление сам и один раз перезагрузит страницу.
- Данные (дети, сборы, оплаты) хранятся локально и никогда не покидают устройство.

## Структура данных

Основные данные (дети, сборы, взносы, расходы) лежат в `localStorage`, а фотографии
чеков — в IndexedDB (`src/app/photos.ts`), чтобы не упереться в лимит localStorage.
Фото автоматически сжимаются перед сохранением (макс. сторона 1400 px, JPEG).

Архитектура хранения вынесена в `src/app/storage.ts` (интерфейс `StorageAdapter`).
Чтобы в будущем добавить облачную синхронизацию (Supabase, Firebase и т.п.),
достаточно реализовать новый адаптер — остальной код менять не придётся.
